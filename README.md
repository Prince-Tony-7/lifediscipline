# Life Discipline check-in

A phone-friendly daily check-in and stats page for the Life Discipline habit tracker (Prince & Jerin).
The page loads and saves data through a Google Apps Script web app; each person opens it with their own private link.

- `config.js` – the Apps Script web app address (the only file you ever edit)
- `index.html` – the app
- `manifest.json`, `icon-*.png` – home-screen app icon
